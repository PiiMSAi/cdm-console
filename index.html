เรียงตาม
สำหรับสัญญาภาษาไทย (CDM / P2W) สี่ช่องล่างนี้ใช้เฉพาะสัญญาไทย ถ้าทำเฉพาะ Cabal PH เว้นว่างได้
ค่าตอบแทนตั้งต้น กรอกไว้ครั้งเดียว เวลาสร้างรอบสัญญาระบบจะเติมให้อัตโนมัติ — ยังแก้รายสัญญาได้ตามปกติ ค่าที่แก้จะใช้เฉพาะสัญญาฉบับนั้น ไม่กระทบค่าตั้งต้น
เก็บข้อมูลอ่อนไหวเท่าที่สัญญาต้องใช้ เลขบัตรประชาชนจำเป็นเฉพาะสัญญา CDM/P2W ที่พิมพ์ลงในเอกสาร — สัญญา Cabal PH ไม่ใช้ ไม่ต้องกรอก · ห้ามกรอกเลขพาสปอร์ต เลขบัญชีธนาคาร หรือพร้อมเพย์ ไม่มีสัญญาฉบับไหนใช้

เทียบ streamer + project + ชุดเอกสาร + ช่วงวันที่ (รวมแถวที่ยังรอส่งขึ้นชีตด้วย)

คลังสัญญาที่สร้างแล้ว

แยกตามโปรเจกต์ แล้วแยกเป็นรอบสัญญา (batch) ข้างในแต่ละโปรเจกต์ — กดที่หัวรอบเพื่อดูรายชื่อ

แถวที่ยังไม่ได้ขึ้นชีต

วิธีสำรอง — คัดลอกไปวางในชีตเอง — ใช้เมื่อ Apps Script มีปัญหา

กดคัดลอก → เปิดชีต Contract_Tracker → คลิกเซลล์คอลัมน์ A ของแถวว่างแถวแรก → Ctrl+V

ก่อนวาง ตรวจว่าคอลัมน์ในชีตยังเรียงเหมือนเดิม แถวเรียงตามหัวคอลัมน์มาตรฐาน 37 ช่อง ถ้าเคยแทรก/สลับคอลัมน์เองในชีต การวางจะเพี้ยน

ส่งขึ้นชีต

ปกติหน้า “สร้างรอบสัญญา” ส่งให้เองอยู่แล้ว — หน้านี้ไว้กดส่งซ้ำเมื่อครั้งก่อนไม่สำเร็จ

รหัสผ่านเข้าคอนโซล

กันคนเดินผ่านมาเปิดลิงก์เฉย ๆ — ไม่ใช่ระบบความปลอดภัยจริง ตัวกันข้อมูลจริงคือข้อความลับของ Apps Script ด้านล่าง

ต้องแก้ไฟล์แล้วแจกใหม่ทุกครั้งที่เปลี่ยนรหัส รหัสผ่านไม่ได้เก็บในชีตหรือที่ไหนที่แก้แล้วมีผลทันที ต้องนำ hash ที่ได้ไปแทนที่ในไฟล์ แล้วอัปโหลดทับที่โฮสต์อีกครั้ง — คนที่ยังใช้ไฟล์เก่าจะพิมพ์รหัสใหม่ไม่ผ่าน จนกว่าจะโหลดไฟล์ใหม่

เชื่อมต่อ Google Sheets

จุดเชื่อมระหว่างคอนโซลกับชีตข้อมูล — ตั้งไว้ให้แล้ว ไม่ต้องแก้ เว้นแต่จะย้ายไปใช้ Apps Script ตัวใหม่

สั่ง n8n ทำงานจากคอนโซล

ตั้งแล้วจะมีปุ่ม “สั่งสร้างเอกสารเดี๋ยวนี้” ที่หน้าภาพรวม ไม่ต้องเปิด n8n เอง ตั้งครั้งเดียวจากเครื่องไหนก็ได้ ทุกเครื่องเห็นค่าเดียวกันทันที

ล้างไฟล์กำพร้าในไดรฟ์ — ไฟล์ที่ไม่มีสัญญาฉบับไหนอ้างถึงแล้ว

เกิดเมื่อลบแถวออกจากชีตด้วยมือแทนที่จะกดปุ่ม ลบ ในคอนโซล ไฟล์เลยค้างอยู่ในไดรฟ์ และเพราะชื่อไฟล์ซ้ำกับฉบับจริงทุกตัวอักษร จึงเสี่ยงหยิบผิดฉบับไปให้เซ็น

นำเข้าข้อมูลจากไฟล์ CSV — ใช้ตอนย้ายข้อมูลครั้งแรก
